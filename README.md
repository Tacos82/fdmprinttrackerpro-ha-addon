# FDM Print Tracker Pro — Home Assistant Add-on

3D printer farm, filament inventory, Moonraker/MQTT telemetry, quotes & invoicing (self-contained SQLite) for Home Assistant OS.

## 1-Click Add Repository

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FTacos82%2Ffdmprinttrackerpro-ha-addon)

Or manually in Home Assistant:
1. Open **Settings → Add-ons → Add-on Store**
2. Click **⋮** (top-right) → **Repositories**
3. Paste `https://github.com/Tacos82/fdmprinttrackerpro-ha-addon` and click **Add**
4. Install **FDM Print Tracker Pro**, configure your timezone (`Europe/Dublin`), and click **Start**

See [INSTALL_HAOS.md](./INSTALL_HAOS.md) for the full visual install manual.
